#### KV Cache 压缩/驱逐

- **CacheCraft: Discovering KV Cache Eviction Policies via LLM-Guided Program Evolution**
  （arXiv 2608.14555）— 提出用 LLM 引导的程序进化（program evolution）方法自动发现 KV
  cache eviction 策略的可执行程序，而不是像 SnapKV/H2O/Ada-KV 等由研究者手工设计打分/
  淘汰规则；是"把 eviction policy 发现过程本身自动化"这一方法论方向的新尝试，与已收录的
  各类手工设计 eviction 方法构成方法论层面的正交延伸。本轮网络环境无法直接访问
  arXiv/HTML 全文（egress 被拦截），仅依据搜索引擎摘要整理，具体压缩比/精度数字未核实，

#### Systems / Serving

- **An Internet for the KV Cache: Rethinking Classical Infrastructure Boundaries in the
  LLM Inference Age**（arXiv 2608.01526）— 愿景/立场型论文（"call for arms"）：主张 LLM
  推理已从纯计算问题演变为以 KV cache 为中心的全球规模内容分发问题，提出按
  model-specific 指标（prefill FLOPs、KV cache 大小）、infra-specific 指标（GPU 成本、
  存储成本、网络带宽）、application-specific 指标（复用频率、工具调用时长、轮次数）联合
  决策 KV cache 的跨数据中心/云区域/边缘节点放置与路由，呼吁社区研发面向 KV cache 的互联
  协议/控制面/缓存感知路由机制；不是具体系统实现，而是给已收录的 KV cache offloading/
  跨区域调度类工作（如 Spatial Prefix Caching for Wireless Edge LLM Inference,
  2608.01126）提供的更高层基础设施愿景框架；8/1 挂出，本轮补录（检索索引延迟）。

#### Agent Runtime × LLM Runtime 协同

- **Learning Agent Execution for KV-Cache Management in Agentic Serving**（CacheScout，
  arXiv 2608.14624）— 面向多 agent LLM serving 的 agent-aware KV-cache 运行时层：核心
  论点是未来 KV cache 复用由 agent 执行语义（而非单纯 cache recency）决定；在线学习 agent
  执行转移概率（不需要预定义 workflow 图或离线训练）、结合 survival-probability 驱逐和
  异步预测性预取，在 vLLM 上实现。与已收录的 Efficient Serving for Dynamic Agent
  Workflows（2605.06472，预测式驱逐/预取但依赖训练）、CacheWise（2606.16824，coding
  agent 场景 prefix-aware 调度）、TokenCake（2510.18586）构成同一"把 agent 执行结构暴露
  给 KV cache 调度层"方向的又一数据点，这次强调在线学习、免离线训练。受 egress 限制未能
  访问全文核实具体数字，基于搜索摘要整理；8/14 挂出，本轮新收录（检索索引延迟）。
