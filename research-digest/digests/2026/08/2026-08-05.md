### 🔥 今日必看

- **AnchorKV: Anchor-Residual KV Cache Compression**（arXiv 2608.02901，Malik Khalaf / Yara
  Shamshoum / Nitzan Hodos / Yuval Sieradzki / Assaf Schuster，机构未独立核实但 Assaf Schuster
  为 Technion 教授，8/3 挂出）— 提出一种不淘汰任何 token 的压缩路线：只用少量精确存储的
  "anchor" token 表示整个 cache，其余每个 token 表示为相对最相似 anchor 的残差，只对预期
  最影响输出的残差做选择性精炼。70B 规模下声称 20x cache 缩小、保留 99% 全量 cache 分数。
  与 eviction（直接丢 token）和量化（压缩比有限）路线都不同——是本轮 tier_0/tier_1/watchlist
  三路独立检索都命中的当日最扎实新论文。

- **Output-Aware Rotation for INT2 KV-Cache Quantization**（arXiv 2608.02691，方法名 OptR，
  Vincent-Daniel Yun 等，USC / Seoul National University / Inha University，8/3 挂出）—
  针对 INT2 超低比特 KV cache 量化：此前基于旋转的方法（如 OSCAR 一类）在 attention 读出
  完成前就优化 cache 统计量或 proxy 重构误差，OptR 则把 post-W_O（attention 输出投影后）
  的误差显式分解为 key 项和 value 项，通过完整 INT2 量化+attention 路径学习按 head 的正交
  校正旋转——直接优化"真正到达模型输出的误差"而不是 cache 层面的代理指标。同样是本轮
  tier_0/tier_1/watchlist 三路独立检索命中的论文。

### 🗑️ 过滤掉的

- **AcceptMoE: Commitment-Weighted Self-Sizing Verifier Expert Sets for Efficient MoE
  Speculative Decoding**（arXiv 2608.02989，8/3 挂出）— 新鲜命中但核实其管理的是 MoE
  speculative decoding 场景下的专家权重 cache/residency，不是 token 级 KV cache，判定超出
  当前追踪范围，过滤。
- **From Chains to Trees: Parent-Conditioned Drafting for Semi-Autoregressive Speculative
  Decoding**（arXiv 2608.02123，PCTree，8/3 挂出）— 新鲜命中，是 DSpark（2607.05147）draft
  tree 结构的后续工作，但只涉及 draft/verify 树结构与验证预算分配，未见 KV cache 管理机制，
  过滤。
- **Distractor-Aware Truncation: Disentangling Context-Length Effects from Signal Loss in
  Long-Context LLM Benchmarks**（arXiv 2608.03297，8/4 挂出）— "long context serving LLM"
  关键词命中，但核实是纯 benchmark/评测方法论工作（用 Claude/GPT-5.5 测试短而相关的上下文是否
  优于长上下文），不涉及 KV cache 系统机制，过滤。
- **PAST-Bench: Benchmarking the Foundations of Recursive Self-Improvement in Personal
  Agents**（arXiv 2608.04003）— tier_2 命中，但是纯 agent 能力评测 benchmark，未讨论任何
  KV/context 管理机制，按 deprioritize 规则过滤。
- **Pruned BPE**（arXiv 2608.00837）— "token pruning attention" 关键词的假阳性命中，实际是
  tokenizer 词表剪枝，与 KV cache 无关；提示该关键词后续可能需要加限定词（如改为
  "token pruning KV cache"）以减少 tokenizer 层面的误报。
