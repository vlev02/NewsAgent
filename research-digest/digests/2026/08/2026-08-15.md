### 🔥 今日必看

- **Thought-Aware KV Cache Compaction for Reasoning via Adaptive Attention Matching**
  （arXiv 2608.12331）— 把推理模型 chain-of-thought 的层级结构显式引入 MIT 提出的
  Attention Matching 式快速 KV cache 压缩流程：先做 thought segmentation 把推理轨迹
  切成推理块，再按每段的重要性/长度做自适应压缩预算分配，并对高关注度的关键推理锚点
  token 做 pivotal token protection，不再对所有 token 一视同仁；是已收录的 Fast KV
  Compaction via Attention Matching（2602.16284）在推理模型场景下的针对性扩展，与
  RestoreKV（2608.01247）、CONF-KV（2605.24786）同属"按重要性动态分配压缩预算"这条
  路线里最新的一环；8 月挂出，本轮新收录。

- **Keeping the Cache Warm Pays: Keepalive Economics for Agentic Workloads**
  （arXiv 2607.19214）— 量化 agentic workload 对主流 LLM 厂商（Anthropic/OpenAI/
  Google/DeepSeek）prompt caching 机制的系统性破坏：agent 发请求后常需等待工具执行/
  人工审批数分钟，缓存前缀往往在此期间被驱逐，后续请求被迫重新支付全额 prefill；提出
  client-side keepalive，在等待间隙按各家 TTL 内最大安全间隔（如 Anthropic 约 4 分钟，
  而非社区常见的 30 秒惯例）重放前缀保温，可把 pause 后请求成本降低最高 12.5x，且证明
  30 秒惯例比经济最优频率贵 8 倍；与已收录的 Don't Break the Cache（2601.06007）构成
  agentic prefix cache 失效代价问题的另一个视角——这次从计费/经济学而非评测角度量化；
  7/21 挂出，本轮补录。

#### Systems / Serving

- **LiveMem: Maintaining Memory State Continuity in Long-Running LLM Inference**
  （2608.02515）— 面向长程运行的 assistant/agent 场景，指出现有 context 保留/摘要/
  检索方法都无法在整个生命周期内提供与当前工作上下文变化无关的持久状态；提出 LiveMem，
  给预训练全注意力 LLM 额外增加一个固定容量的 memory state 用于跨生命周期保存历史信息，
  主 attention 路径则只维持有界的 KV 窗口；LongMemEval 上即使支撑证据已从当前上下文
  移除，仍能依据 memory state 作答；是"有界 KV 窗口 + 外部持久状态"这一架构组合在长程
  agent 记忆场景的新实例；8/3 挂出，本轮补录。

#### Agentic Context 管理

- **Keeping the Cache Warm Pays: Keepalive Economics for Agentic Workloads**
  （2607.19214）— 见"今日必看"。
- **ACM: Agentic Context Management for Long Horizon Tasks**（2607.23809）— 针对
  agentic 任务长程多轮持续累积上下文、现有压缩方法固定触发规则和推理焦点脱节的问题，
  提出让 agent 自主决定何时压缩上下文、把被丢弃内容卸载到外部记忆系统、按需检索回填，
  配套一套后训练 pipeline 构造上下文管理示范数据；论文明确指出该方法同时降低模型推理
  负担和 server 端 KV-cache 开销，压缩由 agent 自身推理状态驱动、在触达上下文上限前
  主动进行（呈锯齿状压缩曲线）；CMU/Meta，7/26 挂出，本轮补录。
