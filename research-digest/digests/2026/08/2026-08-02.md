### 🔥 今日必看

- **The risk of KV cache compression**（arXiv 2607.01520，Lukas Haverbeck，RWTH Aachen University，7/1
  挂出）— 从极小极大风险（minimax risk）角度刻画 KV cache 压缩何时能被证明保持任务准确率，分别给出
  适配 prefill 阶段与自回归解码阶段的压缩设计原则；直接挑战 SnapKV/H2O 等启发式压缩方法"默认安全"的
  隐含假设，与此前收录的 Error Certificates for KV-Cache Eviction（2607.21475）对随机化驱逐理论
  保证的关注形成呼应，两者共同构成对确定性/启发式压缩-驱逐方法可信度基础的理论审视。本轮从早于窗口
  的历史遗漏中补录。

- **PrefixWall: Mitigating Prefix Caching Side Channels in Shared LLM Systems**（arXiv 2603.10726，
  3 月挂出）— 关注共享/多 agent LLM 系统里 prefix caching 暴露的侧信道风险：攻击者可通过响应延迟
  差异探测其他租户的 prefix 内容，提出监测 cache 复用模式并按需隔离 prefix 的缓解机制。与此前收录的
  HijackKV（2607.19957，内容匹配复用被投毒）构成"prefix/position-independent 复用安全风险"主题
  的另一侧面——一个是复用带来的内容污染风险，一个是复用本身泄露的侧信道风险，两者共同对"复用越多
  越好"的默认假设提出安全维度的挑战。本轮从早于窗口的历史遗漏中补录。

#### KV Cache 压缩/驱逐

- **High-accuracy Low-Bit KV-Cache Quantization via Local Distribution Restoration**（arXiv
  2607.16248，7/16 挂出）— 提出通过恢复量化引入的局部分布偏移来提升低比特 KV cache 量化精度，延续
  KIVI 一类量化压缩路线，与淘汰/合并类方法（H2O/SnapKV/Cache Merging）正交，是压缩维度里独立技术
  分支的增量改进。
- **The risk of KV cache compression**（arXiv 2607.01520）— 见上方"今日必看"。

#### Systems / Serving

- **Load-Aware Prefill Deflection for Disaggregated LLM Serving**（arXiv 2607.02043，Microsoft：
  Shrikara Arun / Anjaly Parayil / Srikant Bharadwaj / Renee St. Amant / Victor Rühle，7/2 挂出）—
  在 vLLM 上实现 prefill deflection 调度器，让 decode 节点在不违反 TBT SLO 前提下临时承担
  chunked-prefill 任务，缓解 DistServe/Mooncake 一类 P-D 分离架构下 prefill/decode 负载不均问题，
  P95 TTFT 最高降低 81%；是 disaggregated serving 路线的直接系统扩展。
- **When Hidden States Drift: Can KV Caches Rescue Long-Range Speculative Decoding?**（arXiv
  2604.26412，4 月挂出）— 分析基于隐藏状态的投机解码 drafter 在长距离推测时的精度衰减问题，提出用
  目标模型完整 KV cache 作为显式上下文来校正 drafter 预测，把 KV cache 管理与投机解码准确率直接
  挂钩，是该交叉方向里少见地把 KV（而非仅 token）作为核心变量的工作。

#### Agentic Context 管理

- **AgentKVShift: Efficient KV Cache Reuse for Agentic Memory Systems**（arXiv 2607.21604，UC San
  Diego，~7/21 挂出）— 提出训练无关、探针引导的 KV 残差修正方法，针对 agentic memory 系统里被
  检索出的记忆单元在跨会话复用时产生的 KV 分布偏移问题：只需刷新 10%-30% 的 KV 即可逼近全量重算
  效果。把 CacheBlend/CacheClip 式"部分重算"思路从 RAG 场景延伸到 agentic memory 的非前缀 KV
  复用，与 KVCOMM 的跨 agent KV 对齐问题设定接近。
- **UltraQuant: 4-bit KV Caching for Context-Heavy Agents**（arXiv 2606.20474，6 月挂出）— 面向
  长上下文 agent 场景的 4-bit KV cache 量化方案，延续此前 Q4 持久化 KV（2603.04428）、TriAxialKV
  等量化路线，把量化压缩收窄到 agent 高频长上下文场景，增量式贡献。
- **TokenDance: Scaling Multi-Agent LLM Serving via Collective KV Cache Sharing**（arXiv
  2604.03143，4 月挂出）— 针对多 agent 同步轮次+共享输出块导致的 KV 冗余，用 All-Gather 模式的
  KV Collector 做集体式 KV 复用，是 ForkKV（copy-on-write）、KVFlow（静态调度）之外的第三种多
  agent KV 共享范式，面向同步协作而非独立并发 agent 场景。
- **What to Keep, What to Forget: A Rate-Distortion View of Memory Compaction in LLMs and
  Agents**（arXiv 2607.08032，7/8 挂出）— 提出统一 rate-distortion 理论框架，把 KV cache
  淘汰/量化、prompt 剪枝蒸馏、架构状态压缩、agent 记忆整合都纳入同一"信息保留-资源预算-任务效用"
  目标下建立跨层分类法；少见地把 KV cache 层和文本/记忆层放进同一理论视角讨论，可用作后续判断某项
  agent 记忆工作是否真正触及 KV 层的参照系。
- **PrefixWall**（arXiv 2603.10726）— 见上方"今日必看"。
