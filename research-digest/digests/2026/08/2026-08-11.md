### 🗑️ 过滤掉的

- **TRACE / "Toward Reliable Context Compression for Long-Horizon Agents: An
  Empirical Study of Execution Instability"**（arXiv 2608.06503，UVA + Nokia，
  8/6 挂出）— 研究反复的 context compaction 如何削弱 agent 对近期交互的响应、
  增加被阻塞动作与重复探索；提出 verifier-guided 框架，通过对同一环境状态的
  paired closed-loop continuation 评估单次 compaction 事件，并据此优化一段
  自然语言压缩 prompt（模型本身冻结不训练）。核心机制停留在"优化压缩用的
  自然语言 prompt"这一文本层面，未触及 KV cache 的存储/复用/驱逐机制，按
  keywords.yaml 的 deprioritize 规则（"agent prompt engineering / planning
  框架本身（无 serving/KV 层贡献时）"）过滤。
- **Archer: Adaptive Reuse of Cached Hidden States for Efficient Rollback in
  Diffusion Language Models**（arXiv 2608.08086，上海交大/南开/北大，8/8
  挂出）— 面向 diffusion language model 的 rollback 场景，做 prompt 侧隐藏
  状态复用、response 侧同步刷新的免训练缓存方法。虽然标题含"cache"且与
  KV cache 概念相邻，但服务的是扩散式（双向迭代去噪）生成范式，机制与
  自回归 LLM 的因果 KV cache 复用/驱逐不是同一问题；本方向目前聚焦自回归
  LLM serving（vLLM/SGLang/PagedAttention 一脉），暂判定为跨范式的背景
  参考，不计入"新论文"收录。
- 本轮检索到的其余候选（EVICPRESS、SeKV、Kamera、SpectrumKV、TraCT、
  VeriCache、SAECache 等）均为已知背景工作或超出 24-48 小时窗口，不重复列出。
