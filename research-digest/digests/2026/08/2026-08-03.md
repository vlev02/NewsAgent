### 🔥 今日必看

- **Irminsul: MLA-Native Position-Independent Caching for Agentic LLM Serving**（arXiv
  2605.05696，5/7 挂出）— 指出 agentic workload 每轮都会把内容完全相同的 token 放到序列中
  不同位置，导致 prefix cache 在首个偏移字节处就失效，运营方报告 TTFT 尖峰达 10-16 秒；提出
  扩展 SGLang radix cache，用 CDC 分块内容哈希做 key、配合 k_r 的 δ-rotation 规则，利用 MLA
  架构（DeepSeek-V2/V3/R1、Kimi-K2/Moonlight、GLM-5、Mistral Large 3 均采用）原生实现位置
  无关缓存。与此前收录的 HijackKV（位置无关复用被投毒）、PrefixWall（位置无关复用侧信道）构成
  同一主题的第三个视角——前两者分别是攻击和侧信道防御，这篇是架构原生的正面解法，值得跟进后续
  是否有人从安全角度审视它引入的新攻击面。

- **KVarN: Variance-Normalized KV-Cache Quantization Mitigates Error Accumulation in Reasoning
  Tasks**（arXiv 2606.03458，Huawei，6/2 挂出）— 指出现有 KV cache 量化方法多在 prefill 式
  场景下评估，而自回归解码下量化误差会随时间步累积、主要由 token scale 估计错误驱动；提出
  免校准量化方案，对 K/V 做 Hadamard 旋转 + 双轴方差归一化，在 MATH500/AIME24/HumanEval 等
  推理基准的 2-bit 精度下取得 SOTA。已开源为 vLLM 原生量化后端（huawei-csl/KVarN），宣称
  3-5x 上下文扩容、吞吐超 FP16、精度持平 FP16、免校准、一行 flag 开启——是本轮少见的"论文 +
  可用 vLLM 集成"双落地案例。

### 📄 新论文

#### KV Cache 压缩/驱逐

- **KVarN**（arXiv 2606.03458）— 见上方"今日必看"。
- **CONF-KV: Confidence-Aware KV Cache Eviction with Mixed-Precision Storage for Long-Horizon
  LLM Inference**（arXiv 2605.24786，CMU，5/24 挂出）— 把下一 token 分布的熵/log-prob
  margin/top-token 质量映射为有界置信度分数，据此按步动态选择 cache 预算（不确定时保留更多、
  确信时激进裁剪），预算内再按 EMA 注意力质量 + recency 淘汰、保留最新 token 的硬保护窗；
  免训练、不改权重，可直接插入标准生成循环；同等内存下 CONF-KV-L 消除 512-token 滑窗与全 KV
  之间 74% 的困惑度差距（GPT-2 上验证，规模较小）。

#### KV Cache 复用 / Position Re-indexing

- **Irminsul**（arXiv 2605.05696）— 见上方"今日必看"。

#### Systems / Serving

- **SwiftCache: Efficient LLM Serving for Multi-turn Conversations with Heterogeneous KV Cache
  Sharing**（arXiv 2606.16135，6/15 挂出）— 面向多轮对话/agent 场景，让同一服务器内 KV cache
  需求低的异构模型把闲置 GPU 显存捐给高需求模型存储前缀缓存，经 NVLink 做跨模型 KV cache
  共享、避开慢速 PCIe 搬运；相比 SOTA 基线 P99 TTFT 最高降 69%、最大支持上下文长度提升最高
  3.98x，对协同部署模型的干扰较小。

#### Agentic Context 管理

- **GraphFlow: A Graph-Based Workflow Management for Efficient LLM-Agent Serving**（arXiv
  2605.22566，上海交大，5/21 挂出）— 指出现有 workflow 辅助的 agent serving 系统依赖预定义
  模板 + 浅层匹配，难以捕捉深层语义关系、难以泛化到未见任务；提出统一图 wGraph 表示
  workflow，任务自适应生成 workflow 子图，并利用 wGraph 拓扑结构管理执行状态，在重叠
  operation 之间实现 KV cache 的高效正确复用——是 Parrot/Autellix/KVFlow 之外，把"workflow
  结构感知"和"KV 状态复用"直接绑定的新尝试。
- **TraceLab: Characterizing Coding Agent Workloads for LLM Serving**（arXiv 2606.30560，UW
  SyFI Lab，6/30 挂出）— 开源约 4300 条编程 agent 会话的真实 trace（35 万 LLM 步/43 万工具
  调用，取自 Claude Code/Codex 日常使用），刻画编程 agent workload 特征：长自治循环、长上下文
  短输出（中位数 119K 前缀 token/875 append token/214 输出 token）、工具调用分布重尾、prefix
  cache 命中率高但不完美；为后续 agentic 场景 KV cache 调度设计提供实测依据，背景性收录。
- **CONF-KV**（arXiv 2605.24786）— 见上方"KV Cache 压缩/驱逐"，因面向 long-horizon 推理同时
  交叉相关。
- **SwiftCache**（arXiv 2606.16135）— 见上方"Systems / Serving"，因直接面向多轮对话/agent
  场景同时交叉相关。

### 🗑️ 过滤掉的

- **AgenticCache: Cache-Driven Asynchronous Planning for Embodied AI Agents**（arXiv
  2604.24039）— 核实其"cache"缓存的是文本层的 plan 决策/转移序列（"runtime cache of
  frequent plan transitions"），本质是 plan 级 memoization/语义缓存，不涉及 KV cache 张量
  本身，不落到 KV/cache 层机制，按 deprioritize 过滤。
- **A Workflow-Aware Serving Layer for Agentic Applications**（arXiv 2607.02942，即
  Dyserve）— 核实其核心贡献是用 ILP 在异构后端池中为 workflow DAG 各节点求解
  (model, verifier) 选择以权衡精度/延迟，未见涉及 KV cache 内部机制，过滤。
- **Jet-Long: Efficient Long-Context Extension with Dynamic Bifocal RoPE**（2607.07740）—
  本质是 RoPE 位置外推变体，不含具体 KV cache 压缩/驱逐/复用机制，沿用此前判定过滤。
- **tier_0** 的 "attention sink" / "StreamingLLM" / "token pruning attention" / "token
  merging ViT LLM" 命中继续被纯机制可解释性论文、视频流式理解综述、纯视觉 Transformer 工作
  占据，无 LLM KV cache 系统层贡献，过滤。
- **tier_2**（本 tier 假阳性率最高）：Self-GC（2607.00692）、PEEK（2605.19932）、SAGA
  （2605.00528）、PPD Disaggregation（2603.13358）、TVCACHE（2602.10986，工具调用结果的
  语义级缓存而非 KV 层机制）、"Plans Don't Persist"（2606.22953）、Rethinking Memory
  Mechanisms of Foundation Agents 综述（2602.06052）等，均未确认涉及 KV cache 内部机制或
  为纯文本/调度层贡献，按 deprioritize 过滤。
