### 🔥 今日必看

- **ReCache: Efficient KV Cache Reuse and Compression for Tool-Augmented LLM Agents**
  （arXiv 2608.19662，8/20 挂出，本轮最新）— 指出 agentic LLM 反复以不同组合/顺序编码
  工具与技能 schema，标准 prefix caching 无法跨请求复用这些资源级 KV；提出
  resource-wise attention，去掉跨资源交互、给每个资源赋资源局部位置编码，产出
  与组合顺序无关（composition-invariant）的 KV block，再配合按贡献度选路由的
  layer-KV-head-group 可见性限制 + 结构/语义剪枝；在 7 个公开工具/技能使用数据集
  组成的 benchmark 上，resource-wise attention 与稠密调用性能持平（82.3% vs 82.4%
  Inv-F1），TTFT 提速 3.655x。与已收录的 CacheBlend/CacheClip（RAG chunk 级复用）、
  Irminsul（MLA 原生位置无关缓存）不同，这篇把"位置无关/组合无关复用"的适用对象
  从文档 chunk 换成了 agent 的工具/技能 schema，是 tier_2 agentic 场景下 KV 复用问题的
  新落点。

- **CommitKV: Lifecycle-Aware KV Cache Compression via Commit Transitions for Multi-Turn Agents**
  （arXiv 2608.07855，8/8 挂出，本轮补录/检索索引延迟）— 指出现有基于瞬时 attention
  分数的 snapshot 式淘汰方法（SnapKV/H2O 一脉）无法区分"当前不活跃但未来会用到"
  与"已经完成使命"的信息，容易误删暂时休眠的上下文；CommitKV 把已完成的 agent
  事件切成 token page，比较每个候选页在"工具调用提交前"与"工具调用返回结果并入
  上下文后"两个时间点的删除影响，用这一 commit transition 信号识别 KV 的生命周期
  阶段；6 个 LLM × 8 个 benchmark × 多档 KV 预算上，比最强压缩基线最多高
  22.24 个百分点准确率，端到端最高 5x 加速。是"按重要性动态分配压缩预算"路线
  之外、专门针对 agent 轨迹里"重要性会随工具调用节点周期性回升"这一现象给出
  显式建模的新思路。
