### 🔥 今日必看

- **Trust the Mass: Forced Weights in KV-Cache Eviction**（arXiv 2608.25230，Jack Shi / Jerry
  Gu，Stanford，8/25 挂出）— 对 5 个模型的 168,192 条 attention 行做实证分析，发现"直接保留
  权重最大的 key"这一朴素策略已经接近最优（与暴力搜索得到的最优子集相比，gap 中位数仅
  2-5%）；据此提出现有 eviction 方法之间报告的性能差距，主要不是来自"token 重要性打分"
  算法本身的优劣，而是来自**实现层面的内存占用方式**——很多号称 query-agnostic 的方法实际
  上仍在显存里保留了完整 cache（只是用 mask 标记哪些"被驱逐"），只有真正做 per-head ragged
  存储才能兑现内存节省。这直接挑战了 SnapKV/H2O/ChunkKV 等一整条"设计更聪明的重要性打分
  函数"路线的核心叙事：如果朴素 top-weight 已经接近最优，那么这条线过去积累的大部分复杂度
  可能是在优化一个已经很小的 gap，真正的工程收益在存储层而不是算法层。与此前收录的
  Error Certificates for KV-Cache Eviction（2607.21475）、The risk of KV cache compression
  （2607.01520）构成同一批"审视确定性 eviction 方法可信度基础"的第三个数据点，但这次矛头
  从"理论保证缺失"转向"评测本身在测量错误的东西"。

#### KV Cache 压缩/驱逐

- **Trust the Mass**（arXiv 2608.25230）— 见上方"今日必看"。
- **Squeezing the Cache, Preserving the Truth: Monotonic Equipotential Allocation with
  Geodesia-KV**（arXiv 2608.23599，Dentamaro / Auteri / Pirlo；提交日期在检索结果中出现
  冲突——一处来源标注 8/19，另一处标注约 8/23，本轮未能核实原文日期，待下一轮确认）—
  训练无关的 KV cache 策略族：块级单调精度分配（精确 / 标量量化 / 质心三级阶梯）+
  精确率失真残差 + query-sparse 读取，明确区分"常驻位宽（resident bits）"与"读取带宽
  （read bandwidth）"两个此前常被混淆的指标；WikiText-2 16k 上下文的 5-bit 操作点优于
  KIVI-4，消费级 16GiB GPU 上可支持百万 token 上下文，峰值显存节省达 71.7%，已实现为
  vLLM 插件（GeodesiaKVCacheManager）。与 KVarN/OptR/NOVA-KV/SAKI 同属量化压缩路线，
  以"分级表示 + 按需提升精度"为新颖点，且有实际 vLLM 落地。

### 🏗️ 工程/生态动态（vLLM / LMCache / SGLang 等仓库的新 release、RFC、issue 讨论）

- **vLLM**：新发现正式 release **v0.28.0**（8/24 发布，此前记录为 v0.27.1/8-11 的
  patch-only 版本，本次是有实质内容的 minor 版本升级）。KV cache 相关改动密度很高：
  - 多层（tiered）KV offloading：新增磁盘 offloading 支持（SimpleCPUOffloadConnector）、
    可通过 module_path 接入的外部次级层管理器、partial secondary-tier load、tiering
    指标、跨并行配置一致的 "canonical CPU layout"。
  - Prefix caching：MLA chunked context 的 per-request 调度、partial-tail 前缀复用
    （更细粒度的前缀匹配）、backend-published KV packing（layout 重构）、关闭 prefix
    caching 时恢复 LIFO free-block 复用顺序。
  - Model Runner V2 新增 E/P/D（Encode/Prefill/Decode）分离支持。
  - Mamba/混合架构：prefix caching 默认开启。
  这是本轮扫描里信号密度最高的单条动态，直接推进"KV cache offloading"与"disaggregated
  prefill decode"两个长期跟踪主题的生产级实现，建议下一轮细读 release note 全文。
- **SGLang**：仍为 v0.5.18（8/22 打 tag），未发现新版本。
- **LMCache**：仍为 v0.5.4（8/20 打 tag），未发现新版本。
