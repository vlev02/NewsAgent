### 🔥 今日必看

- **Practical Online KV Cache Compaction for LLM Agents: An Empirical Study**（arXiv
  2608.00902，Yujian Liu 等，UC Santa Barbara/LinkedIn，8/2 挂出）— 直接切中 agentic 场景下
  KV cache 管理的核心难题：不同于此前离线上下文压缩，agent 轨迹里每个刚完成的对话轮次必须在其
  未来相关性尚未知晓前就被压缩。系统对比 token eviction（TE）与 attention matching（AM，复用
  Fast KV Compaction via Attention Matching/2602.16284 的压缩技术）两类策略，并用边界/重复
  prefill/延迟未来生成等廉价代理信号替代未知的未来查询；在 BrowseComp-Plus/WideSearch 上发现
  "立即压缩"会显著损害性能，而用 agent 未来查询做代理的"延迟压缩"能补回大部分差距。是本轮四路
  独立检索（tier_0/1/2 全部命中）唯一交叉确认的论文，说明它确实是本周期内该方向最扎实的新工作。

- **RestoreKV: Recovering Full-Cache Behavior Under Aggressive Query-Agnostic KV Cache
  Eviction**（arXiv 2608.01247，Changwoo Baek / Seungjun Shin / Kyeongbo Kong，8/1-8/2 挂出）
  — 针对 query-agnostic KV cache 淘汰（上下文只压缩一次、生成的 cache 被任意未来查询复用）在
  紧张预算下性能崩溃的问题，提出 LoRA 适配的"restore token"：prefill 后单次 attend 全量 KV
  cache，生成一份上下文条件化的紧凑"恢复 cache"，在与被淘汰内容相同的总 KV 预算内、不改变原有
  重要性打分器和淘汰规则的前提下补偿信息损失。在 KVzip+ 基础上，KVPress 基准 16x 压缩下达到
  86.4 RULER 准确率，开销 <0.5%——是本轮 tier_0/1/2 三路检索都独立确认的第二篇论文，核心
  KV 淘汰/复用方向的扎实增量。

### 📄 新论文

#### KV Cache 压缩/驱逐

- **RestoreKV**（arXiv 2608.01247）— 见上方"今日必看"。
- **S⁴R: Selective Sampling, Subspaces, and Sparse Reconstruction for Compressed Long-Context
  KV Caching**（arXiv 2608.00528，8/1 挂出）— 指出离线低秩 KV cache 压缩方法依赖外部校准
  数据、在线方法则需承担对完整 prompt 做分解的高计算成本；提出用 prompt 感知初始化从选择性
  采样的 token 构建 K/V 子空间基，解码时只对信息量高的位置做稀疏重构，兼顾免校准与低单步开销。
- **Does Accuracy Equal Evidence? Reasoning Faithfulness under KV Cache Compression**（arXiv
  2608.01631，Mengting Ai / Jingrui He / Yue Guo，UIUC，8/1-8/3 挂出）— 对 10 种 token
  淘汰类 KV cache 压缩方法 + 1 种量化方法，在数学/科学 QA/临床/长上下文任务上做实证评估，
  发现压缩对"最终答案准确率"和对"支撑该答案的推理链忠实度/一致性"的保留程度可以脱钩——准确率
  能保住而推理证据链已经劣化。与已收录的 The risk of KV cache compression（2607.01520）、
  Error Certificates for KV-Cache Eviction（2607.21475）构成同一"压缩方法可信度审视"主题的
  第三个数据点，这次是从"答案是否真的由保留下来的证据支撑"这一新维度切入，直接挑战"准确率不掉
  就是安全的"隐含假设。

#### Agentic Context 管理

- **Practical Online KV Cache Compaction for LLM Agents**（arXiv 2608.00902）— 见上方
  "今日必看"。
- **TokTier: Exact Stateful Tokenization for Agentic LLM Serving**（arXiv 2607.29678，
  Zhang / Cao，7/31 挂出）— 指出 agentic coding 场景下重复提交的长 transcript 存在
  tokenization 边界失配问题，会打断 prefix cache 复用；在 94.1% 的 cache 命中率下，
  tokenization 本身的开销就占到 TTFT 的 64%，揭示了此前工作只关注 KV 层面复用、却忽视
  tokenizer 层面代价的盲区——是一个此前 tier_2 检索里没出现过的新角度。
