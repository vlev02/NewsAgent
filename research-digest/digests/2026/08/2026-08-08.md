#### Agentic Context 管理

- **Agentic Coding in the Wild: Characterizing GitHub Copilot Traces at Production
  Scale**（arXiv 2608.00101，Banruo Liu / Haoran Qiu / Íñigo Goiri / Rodrigo
  Fonseca / Ricardo Bianchini / Esha Choukse，Microsoft Azure，8/1 挂出）—
  首个生产级规模的 agentic coding workload 特征刻画：采样自 GitHub Copilot 的真实
  trace，涵盖 320 万用户、1300 万 session、7.61 亿次 LLM 调用、95T token。核心发现
  直接量化了本追踪长期关心的问题——agentic coding session 由稀疏的用户发起轮次构成，
  每轮展开成自治的 agent loop（LLM 调用几乎总与工具执行耦合），这一结构导致 KV cache
  命中率在轮内平均达 90%，但跨轮次边界骤降到 55%，且在模型切换、context compaction
  等事件后被大幅失效；为 CacheWise、TokTier、TraceLab 等此前收录的 agentic serving
  workload 特征化工作提供了迄今为止规模最大的生产级实证支撑，也为 tier_2/tier_4
  "如何把 agent 语义暴露给 KV cache 调度"方向标定了跨轮复用率的真实基线。tier_2
  agentic workload profiling 关键词命中，此前几轮未搜到，本轮新收录。
