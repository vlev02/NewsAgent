### 🔥 今日必看

- **TOPAS: Workflow-Aware Prefix-State Scheduling for Multi-Agent LLM Serving**（arXiv
  2608.25523，Hongqiu Ni / Han Tian / Chi Zhang / Guopeng Li / Haisheng Tan，8/26 挂出）—
  面向多 agent LLM serving 场景，联合决策保留哪些 agent 的 system-prompt KV cache、驱逐
  哪些、以及在共享 GPU KV cache 预算下调度哪些请求执行；直接落在 serving/KV 层（而非纯
  agent 编排框架本身）；synthetic 多 agent workflow 上把平均/p99 job completion time 分别
  降低最多 39.8%/49.4%。与已收录的 Preble（prefix sharing scheduling）、Autellix
  （agentic serving）、CacheScout（agent-aware KV cache 运行时，2608.14624）构成同一条
  "把 agent 执行结构暴露给 KV cache 调度层"方向的新数据点，这次的切入点是多 agent
  workflow 场景下 system-prompt KV 驻留/驱逐与请求调度的联合决策，是本轮唯一一篇经
  arXiv 摘要页交叉核实作者与日期、且结果量级明确的新命中。

#### KV Cache 复用 / Position Re-indexing

- **Affix Cache for Diffusion Large Language Models（ACache）**（arXiv 2608.26140）—
  面向 diffusion LLM（DLLM）的 KV cache 复用机制：DLLM 通过双向注意力把共享上下文的 KV
  状态与不断演化的生成 token 耦合在一起，使自回归 LLM 常用的朴素 prefix 式复用
  （CacheBlend/CacheClip 一脉）直接失效；ACache 识别少量"Anchor Tokens"选择性重算，
  其余 affix cache 复用不变，声称最高降低 55.7% 的重算延迟。与已收录的各类 autoregressive
  LLM KV 复用工作分属不同架构家族（diffusion vs. autoregressive），是同一大问题（KV 复用）
  在新架构上的正交延伸，暂不构成对现有假设的直接支持/挑战。三路独立检索均确认该
  arXiv ID 存在且主题匹配，但确切作者列表与挂出日期本轮未能核实（环境对 arXiv 直接
  访问受限，检索结果对日期存在矛盾说法——一处指向 6/26，另一处从 ID 前缀推断为 8 月
  下旬），留待下一轮用更可靠渠道核实后补全。
