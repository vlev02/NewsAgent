### 🔥 今日必看

- **HijackKV: New Threat in Position-Independent KV Cache Reuse**（arXiv 2607.19957，USENIX Security
  2026 录用，Yichi Zhang / Zhiqi Wang / Huan Zhang / Yuchen Yang，7/22 挂出）— 指出系统层面为提升
  复用率引入的 position-independent KV reuse（只要文本 chunk 内容匹配就复用 KV，忽略其在序列中的
  位置）带来新的安全威胁：被复用的 KV 编码的是它最初被计算时所处的上下文，一段看似良性的文本 chunk
  可能携带攻击者构造的 prefix 条件；当这段被污染的 KV 在受害者查询里被复用时，即便输入文本完全不含
  攻击者内容，也会静默劫持模型行为。提出 HijackKV，第一个系统化利用该漏洞的攻击框架，验证其严重性
  与可实施性。直接挑战 CacheBlend/MEPIC/CacheSlide/MiniPIC 等 position-independent 复用方案默认的
  "内容匹配即可安全复用"假设，本轮从此前多轮遍历中补录，是本次检索里唯一的 challenges 级别信号。

#### Systems / Serving

- **InferScale: GPU-Native KV Injection for Personalized LLM Serving**（arXiv 2607.27090，Peter
  Li / Prashant Pandey，7/29 挂出）— 面向持久化个性化 context（累积 memory profile、长对话历史）
  的 serving 场景：现有 memory 系统（如 Mem0）每次把检索到的相关片段注入 prompt，迫使 serving
  engine 反复重新 prefill 同样内容，拖高 TTFT；InferScale 预先计算每条 memory fact 的 KV 表示并
  连同语义 embedding 存在 GPU 上，serving 时检索相关 fact 后把其 KV 直接注入 vLLM 的 paged
  cache，跳过重新 prefill。Llama-3.1-8B 上，检索预算 k 从 5 升到 50 时 TTFT 只涨 4%
  （16.6→17.3ms），而 Mem0 同条件下涨 106%（33.2→68.3ms）；k=50 时 TTFT 降 72%-79%
  （3.6-4.8x），准确率 60.3% 略低于 Mem0 的 63.3%，并发负载下吞吐提升 3.7-4.5x。本轮从此前几轮
  遍历漏掉的候选中补录。
