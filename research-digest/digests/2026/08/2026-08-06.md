### 🔥 今日必看

- **Spend Bits Where Queries Look: KV Cache Vector Quantization with Attention-Preserving
  Transforms**（方法名 NOVA-KV，arXiv 2608.04074，Samuel Fernández-Menduiña / Amir
  Ziashahabi / Eduardo Pavez / Antonio Ortega / Salman Avestimehr，USC，8/4 挂出）—
  把 KV cache 量化显式建模为"以 attention 乘积误差为失真度量"的 transform coding
  问题：从校准统计量推出 key/value 各自的闭式最优变换，证明最优 key 变换满足广义
  Parseval 关系，使 attention-aware 失真在变换域退化为普通 MSE，从而可以直接套用
  MSE-optimal 的向量量化器——把此前 OptR（2608.02691，昨日已收录）"显式分解
  post-W_O 误差为 key/value 项"的思路推进到有闭式解、可直接推导量化器设计的理论
  层面。2-bit/元素下仍能保住多数长上下文检索准确率，在 GPT-OSS-20B 这类
  hybrid-attention MoE 模型上优势最明显（此前方法在这类模型上会崩溃）。与
  OptR/KVarN 构成本周"attention-aware 量化路线"的第三个数据点，本轮 tier_0
  检索独立命中。

### 📄 新论文

#### KV Cache 压缩/驱逐

- **NOVA-KV**（arXiv 2608.04074）— 见上方"今日必看"。
- **SAKI: Score-Aware Low-Rank Key Indexing for Long-Context KV Retrieval**（arXiv
  2608.03228，Lin Zhang，Cotality，8/4 挂出）— 现有低秩 KV cache 方法要么保权重、
  要么保 key 方差，都不直接对应推理时真正使用的 attention score；SAKI 推导 rank-r
  key 压缩导致的期望 attention score 失真，证明其等价于协方差加权的低秩目标，
  在 margin 条件下该目标同时改进 top-k recall；最优 rank-r 解由协方差加权
  query-key 算子的 SVD 给出闭式非对称分解。rank 32 下比 PCA 消除 13-30% 的
  top-64 recall 误差（LLaMA 3.1 8B 上 0.748→0.799，Qwen 2.5 7B 上
  0.786→0.850）。与 NOVA-KV 同属"直接优化 attention 层面失真而非 cache 层面
  代理指标"这一路线，但落点是低秩 key 索引而非向量量化。
