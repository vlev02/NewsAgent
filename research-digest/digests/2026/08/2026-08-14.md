### 🔥 今日必看

- **LinearKV: One Cached State Suffices for Position-Independent Caching in Hybrid LLMs**
  （arXiv 2608.11231）— 把 position-independent caching（PIC）从纯全注意力模型推广到混合
  注意力（linear attention + full attention）模型：既有 PIC 方法依赖 token-indexed KV 做
  拼接/局部修复，但混合模型里的线性循环层只暴露一个定长 state，没有 token 维度可拼；
  LinearKV 用 decoupled 初始化——线性层把匹配到的 local state 映射成单一 initial state、
  全注意力层照常拼接 KV——兼容现有 PIC 方法的 token 选择/重算逻辑，不需重训；LongBench
  QA/RULER 8K-32K 上相比全量 prefill 全线降低 TTFT。直接补齐了已收录的 HYPIC
  （2607.01299，首个面向混合注意力模型的 PIC serving 系统）留下的"线性层怎么做 PIC"缺口，
  是 MiniPIC/MEPIC/HYPIC 这条 position-independent caching 谱系里最新的一环，对支持"位置
  无关缓存可以推广到非标准 attention 架构"构成进一步支持。

- **LinearKV**（2608.11231）— 见"今日必看"。
- **SemPIC: Learning Semantic Position-Independent KV Caches**（2607.28069）— 不像
  KV Packet/MiniPIC 那样按原始 chunk 做 position-independent 缓存，SemPIC 学习按语义单元
  编译 query-/layout-独立的 KV，同一份缓存可跨历史顺序、文档排列、检索集合复用（包括 query
  出现在不同绝对位置的排列）；命中时把 KV 分配到最终逻辑位置、重新 RoPE 旋转、只让
  request-specific 的内联 token 走完整解码；三模型四任务上把 mean micro-F1 从 KV Packet
  基线的 0.53 拉到 0.60，接近 Full Recompute 的 0.62。7/28 挂出，此前几轮遍历均未搜到，
  本轮补录。
