### 🔥 今日必看

- **When KV Cache Reuse Fails in Multi-Agent Systems: Cross-Candidate Interaction is Crucial for LLM Judges**（arXiv 2601.08343，Sichu Liang 等）— 对生成型 agent 有效的 KV cache 复用策略，在"LLM 当裁判"场景下会系统性削弱裁判对候选间的交叉注意力（Judge Consistency Rate 显著下降），而端任务准确率看起来稳定，掩盖了复用对裁判决策一致性的破坏。直接挑战"KV cache 复用策略可以跨 agent 角色（执行者 vs 裁判）无差别套用"的假设，是本轮补录里唯一的 challenges 判定，也是本次二次检索的最强信号。
- **Back from the Future: Key-Value Cache Management by Counter-Causal Surprise**（arXiv 2607.27600，Stephen Gould / Anton van den Hengel，7/30 挂出）— 提出"反因果惊奇度"驱逐准则：用反因果注意力掩码判断每个 token 能否被其后已生成的 token 良好预测，能被未来良好预测的视为冗余并周期性驱逐。是 attention-score / 信息论之外的第三种驱逐信号，本次二次检索里唯一真正落在过去 24-48 小时窗口内的新论文。

#### KV Cache 复用 / Position Re-indexing

- **MEPIC: Memory Efficient Position Independent Caching for LLM Serving**（arXiv 2512.16822，
  Qian Wang 等）— watchlist 长期缺口本轮补齐：这就是 7/30 digest 里标记"未能找到对应具体论文"
  的 MEPIC 条目。针对 deep-research/coding agent/RAG 场景下重复处理共享文档/代码 chunk 给 KV
  cache 带来的显存压力，把 chunk KV 对齐到分页存储、将重算粒度从 token 级降到 block 级（仅首块
  request-specific）、在 attention kernel 内通过 RoPE 融合直接去掉位置编码使其余块完全可共享；
  相比现有 position-independent caching 方案减少 HBM 里的重复 chunk KV 最高 2x（长 prompt 下
  达 5x），且不改动模型。2025 年 12 月已挂出，此前多轮遍历均未搜到，本轮补录。

#### Systems / Serving

- **HyMCache: A KV Cache Framework for Multi-Turn LLM Serving with CXL-Hybrid Memory**
  （arXiv 2607.18141）— 多轮 LLM serving 里 KV cache 复用要跨轮/跨 session 扩到 TB 级容量，但
  GPU HBM 和主机 DRAM 太贵撑不住；HyMCache 用 CXL-hybrid memory（小容量设备侧 DRAM 作 staging
  层 + SSD 背靠的大容量远程内存池）承载 KV，利用多轮访问读多、可预测、只追加的特点做请求级前缀
  预取和机会性写缓冲，在真实 CXL-HM 原型上、同等 DRAM 预算下 PD 分离 serving 场景相比本地
  LMCache 吞吐提升 3.0x。7 月中已挂出，此前几轮未搜到，本轮补录。
- **Robust KV Cache Management for LLM Serving under Output Token Length Uncertainty**
  （arXiv 2607.16892，Jiaming Cheng 等）— 指出 KV cache 显存必须在请求到达时就预留、但输出长度
  直到生成结束才知道：预留不足触发抢占式终止+重算，预留过多则浪费显存拖低吞吐；提出联合优化 GPU
  并行配置、按请求类别的 KV cache 预留、跨异构 serving group 的请求路由、以及共享 prompt 的
  prefix caching 的鲁棒管理框架。7 月中已挂出，此前几轮未搜到，本轮补录。

  Bidirectional Cache Transplantation**（arXiv 2607.28495，Alexander Boesgaard Lorup 独立作者，
  7/30）— 审计"一次性重建前缀 KV"是否等价于原始连续推理状态：Qwen2.5 衍生系统 200 条测例显示

#### tier_2 覆盖缺口补录（此前多轮遍历均未搜到，非过去 48 小时新作，但确认此前未收录）

- **KEEP: A KV-Cache-Centric Memory Management System for Efficient Embodied Planning**
  （arXiv 2602.23592）— 具身长时程规划场景的 KV-cache-centric 记忆系统，静态-动态记忆构建+
  多跳记忆重计算+层平衡加载；相比 CacheBlend 类方法 ALFRED 成功率+4.13%、TTFT 降 1.90x。
- **Agent Memory Below the Prompt: Persistent Q4 KV Cache for Multi-Agent LLM Inference on Edge
  Devices**（arXiv 2603.04428）— 端侧多 agent 场景把 KV cache 以 4-bit 量化持久化到磁盘、直接
  加载进 attention 层跳过重新 prefill；Gemma 3 12B/32K 上下文冷启动 TTFT 降 136x。
- **Efficient Serving for Dynamic Agent Workflows with Prediction-based KV-Cache Management
  (PBKV)**（arXiv 2605.06472）— 预测未来 agent 调用来估计 KV cache 复用价值指导驱逐/预取，
  相比 LRU 提速最高 1.85x、相比 KVFlow 静态场景提速 1.26x。
- **Continuum: Efficient and Robust Multi-Turn LLM Agent Scheduling with KV Cache Time-to-Live**
  （arXiv 2511.02230，UC Berkeley/Stanford/Tensormesh/清华）— agentic workload 里工具调用间歇
  暂停会打破常规"新请求到达即驱逐已完成请求 KV cache"的策略；按 reload 代价与保序收益联合决定
  TTL，超时后自动驱逐。
- **LRAgent: Efficient KV Cache Sharing for Multi-LoRA LLM Agents**（arXiv 2602.01053）— 多
  agent 通过 multi-LoRA 分化角色但共享骨干，把 KV cache 拆成共享基座+adapter 相关部分，配合
  Flash-LoRA-Attention 避免物化低秩 cache，吞吐/TTFT 接近全共享 cache。
- **DualPath: Breaking the Storage Bandwidth Bottleneck in Agentic LLM Inference**（arXiv
  2602.21548，DeepSeek/清华/北大）— 多轮 agentic 推理性能越来越受 KV cache 存储 I/O 而非算力
  主导，分离式架构下双路径 KV cache 加载改善负载不均衡，离线吞吐+1.87x、在线+1.96x。
- **KVCOMM: Online Cross-context KV-cache Communication for Efficient LLM-based Multi-agent
  Systems**（arXiv 2510.12872）— 多 agent 场景朴素 KV 复用因跨 agent 前缀 offset 漂移而失效；
  训练-free，用在线锚点池估计并对齐跨 agent 共享内容的 cache offset，复用率超 70% 且无质量损失。
- **Efficient Long-Horizon GUI Agents via Training-Free KV Cache Compression**（arXiv
  2603.00188）— 长时程 GUI agent 轨迹的训练-free KV cache 压缩；本轮仅核实标题与引用上下文，
  具体机制细节待后续核查。
- **TriAxialKV: Toward Extreme Low-Precision KV-Cache Quantization for Agentic Inference Tasks**
  （arXiv 2605.17170）— agentic context 在时间新近度/模态/语义角色三轴上重要性不同，现有量化
  只利用单一维度；三轴打标签+按标签校准+INT2/INT4 混合精度分配，Qwen3-VL-32B 作 computer-use
  agent 时 4.5x KV cache 尺寸下吞吐比 SGLang BF16 基线+30%。
- **Multi-Agent Memory from a Computer Architecture Perspective: Visions and Challenges Ahead**
  （arXiv 2603.10062）— 从体系结构视角审视多 agent 记忆的立场论文，提出三层内存层级(I/O/cache/
  memory)，指出"跨 agent 缓存共享"是关键协议空白；无具体机制，仅作方向性背景收录。
- **ForkKV: Scaling Multi-LoRA Agent Serving via Copy-on-Write Disaggregated KV Cache**（arXiv
  2604.06370，上海交大）— 多 LoRA agent workflow 里各 agent 独立 LoRA 激活导致 KV cache 分化、
  传统 prefix caching 对共享上下文失效；fork+copy-on-write 把 KV cache 解耦为共享大部分+轻量
  agent 专属部分，配合 DualRadixTree，相比 SOTA 多 LoRA serving 吞吐+3.0x。
- **Don't Break the Cache: An Evaluation of Prompt Caching for Long-Horizon Agentic Tasks**
  （arXiv 2601.06007）— 对三家主流 provider 的 prompt caching 在长时程 agentic 工具调用任务上
  系统评测(500+ agent session)，发现连工具调用结果一起缓存有时反而拖慢延迟，只缓存 system
  prompt 更稳定省 41%-80%；对"缓存越多越好"的默认假设提出经验性挑战。
- **PolyKV: A Shared Asymmetrically-Compressed KV Cache Pool for Multi-Agent LLM Inference**
  （arXiv 2604.24971）— 多并发 agent 共享单一非对称压缩 KV cache 池，K 用 int8、V 用 FWHT 旋转
  +3-bit Lloyd-Max 量化；Llama-3-8B 上 15 agent 共享 4K 上下文时 KV cache 显存降 97.7%。
- **QKVShare: Quantized KV-Cache Handoff for Multi-Agent On-Device LLMs**（arXiv 2605.03884）—
  端侧多 agent 间量化 KV cache 交接框架，token 级混合精度+CacheCard 表示；8K 上下文下 handoff
  延迟相对全量重新 prefill 从 1029.7ms 降到 397.1ms。
- **CodeComp: Structural KV Cache Compression for Agentic Coding**（arXiv 2604.10235，港大/
  LMSYS）— 用 Joern 抽取的 Code Property Graph 先验补充纯 attention 信号，避免丢弃调用点/分支
  条件等结构关键但 attention 分数低的 token；同等内存预算下持续优于纯 attention 压缩基线。
- **When KV Cache Reuse Fails in Multi-Agent Systems**（arXiv 2601.08343）— 见上方"今日必看"。
