### 🔥 今日必看

- **SGLang v0.5.20 — 统一 Radix Tree（Unified Radix Tree）prefix cache 命中率提升**（GitHub
  Release，sgl-project/sglang，9/18 22:41 发布）— 引入"统一 radix tree"支持分支点（branching
  point）级别的前缀缓存，官方报告 token cache-hit rate 从 43.8% 提升到 60.8%；同批还带来
  "DSpark under PD"（disaggregated prefill/decode 场景下的解码 context parallelism 投机解码）
  与一个纯 CPU 的 SGLang Simulator（用于 cache 策略/延迟离线研究）。今日整体是清淡窗口（tier_0/1/2
  检索到的高相关新论文几乎全部已在此前 7 天窗口内收录），这是当天唯一有具体量化数据、可验证的
  KV/prefix cache 层面实质性改进，直接服务 tier_1 长期跟踪的 SGLang/RadixAttention 一脉。

### 📄 新论文（按 tier 分类，每条一行：标题 + 一句话 takeaway）

#### KV Cache 压缩/驱逐

- **StackTok: Accelerating VLMs Inference with Budget-Adaptive Visual Token Selection**（arXiv
  2609.16841）— 现有免训练视觉 token 选择方法（如 AdaFV）在"查询相关性"与"视觉覆盖度"间用固定
  权衡系数，本文把查询相关性作为主要优化目标、视觉覆盖度处理为随预算动态校准的约束，自适应选择
  保留的视觉 token；与语言模型侧基于重要性打分的 KV cache eviction（H2O/SnapKV 一脉）正交
  互补——聚焦视觉编码器输出 token 而非语言模型自身 KV cache，可与文本端 KV 压缩联合部署进一步
  压缩多模态推理显存开销；约 9/15 挂出，本轮 tier_0（token pruning attention / token merging
  ViT LLM）检索补录（索引延迟缺口）。

#### Agentic Context 管理

- **Long-Lived Characters, Local Inference: Incremental Memory Maintenance for Game NPCs**
  （arXiv 2609.18935）— 现有 KV cache 失效/修复研究（CacheBlend/CacheClip 一脉，以及本周已收录的
  Contiguity, Not Importance）主要针对通用 agent 场景下检索文档/working memory 被编辑后的整体
  KV 过期问题；本文把同一问题落到游戏 NPC 长期存活角色的"增量记忆维护"场景——角色记忆被修改/撤销
  时不应对整段历史重新 prefill。在量化的 Qwen 混合循环-注意力模型上，运行时精确移除失效的
  attention KV 条目、在序列真实末尾计算替换记录，同时保留未变化的 KV 与持续的循环状态，避免整个
  可复用前缀失效；是"细粒度 KV 失效修复"这一新兴问题簇（与本周 Contiguity-Not-Importance 同源）
  在本地部署游戏角色记忆这一垂直场景下的变体应用，机制上对 agentic 场景的 prefix cache
  invalidation 研究有参考价值；约 9/16 挂出（略早于本轮 24-48 小时窗口，但此前未被收录），本轮
  tier_2 检索补录。
