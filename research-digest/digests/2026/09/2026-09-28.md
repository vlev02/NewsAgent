### 🔥 今日必看

- **Claude Code v2.1.283 新增 `x-claude-code-prompt-id` 网关 hint header**（2026-09-25，
  GitHub release notes 已核实原文；需 `CLAUDE_CODE_GATEWAY_HINT_HEADERS=1` 显式开启）— LLM
  网关可据此把"服务同一条用户 prompt 的所有请求"归组。这是 agent runtime 主动把自己的
  一层结构 ID（prompt 级）随请求带到 serving/gateway 层的实例。
  **对 StructKV 的意义**：回答接口边界调研中"ID 在哪层丢失"——目前 prompt 级 ID 已能出 runtime
  到 gateway，但粒度只到 prompt，message / tool-call / episode 级 ID 仍未见跨层传递；
  StructKV 的插入点（P3 协议）至少要在此基础上再下沉两级。同周 v2.1.281/282 反复修复
  "恢复会话时重发的历史消息形态变化，导致 API 丢弃先前推理 / prompt cache 丢失"，说明
  runtime 侧已把"历史字节稳定"当作与 prefix cache 共存的硬约束——这正是 P1（ReClaim）在做
  prune+reindex 时必须与文本层保持一致的前提，也是"原地编辑不走文本重发"的现实动机。
  （注：来源为 release notes，未见 Anthropic 官方对该 header 用途的进一步论述；判 A 级基于
  其为"跨层 ID 传递"的实证，粒度有限。）
