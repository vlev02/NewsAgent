### 🔥 今日必看

- **DeepSeek-V4.1-Flash: Pushing the Limits of KV Cache Compression**（arXiv 2609.19969，DeepSeek-AI，
  590+ 作者）— 前沿级 552B 参数 MoE 模型技术报告，Causal Encoder-Decoder 架构（解码 16B / prefill 8B
  激活参数），1M token 上下文；提出跨层 KV 复用新方案 Compressed Sparse Attention 2（CSA2）结合 FP4
  KV 量化，把全局（HBM）KV 显存占用压到 890 字节/token，约为上一代 DeepSeek-V4-Flash 的 1/4，并用
  "SWA Bounded Replay" 部署技巧把 SSD/host memory 持久化 KV 占用进一步压到约 V4-Flash 的 1/8；是
  跨层 KV 共享（YOCO/CLA 一脉）与低比特量化两条压缩思路在前沿模型规模上的最新落地，直接服务
  长上下文/agentic workload 的 serving 成本；9/17 挂出，本轮 tier_0/tier_1 联合检索新收录。

### 📄 新论文（按 tier 分类，每条一行：标题 + 一句话 takeaway）

#### KV Cache 压缩/驱逐

- **DeepSeek-V4.1-Flash**（arXiv 2609.19969）— 详见"今日必看"。
- **D-Quant: Driftable Entropy Coding for KV Cache Quantization**（arXiv 2609.19880，Yi Su/Hong
  Liu/Guanghua Yu/Jianchen Zhu）— 现有 KV cache 量化多用固定位宽（2^b 档位）方案，低比特下因 KV
  值分布并非均匀而损失精度；本文观察到旋转+归一化后的 KV 值分布接近高斯，提出用可变长熵编码替代
  固定位宽量化，按分布"漂移"自适应分配编码长度；是 KIVI 一脉旋转感知 KV 量化方法上的新变体，与
  已收录的 Grouped Value Attention（2609.13285，分组 value + 按需重构 key）同属"KV cache
  布局/量化层面精细化"这一分支的最新数据点；9/17 挂出，本轮 tier_0/tier_1 联合检索新收录。

#### KV Cache 复用 / Position Re-indexing

- **Where Should a Document Live: Context, Representations, or Parameters?**（arXiv 2609.17346，
  Nathanaël Carraz Rakotonirina 等，Amazon AGI）— 面向知识注入场景，现有做法在"放进 prompt
  context（RAG）"、"存成 KV cache 式表征（Cartridges）"、"参数化微调"三条路径间缺少受控对比；本文
  系统比较三者，发现在 oracle 设定下 Cartridges（KV cache 式表征）在几乎每个存储预算下都是最准确
  的注入方式，且是唯一在真实多文档检索场景下能匹配上下文学习效果的方法；是 CacheBlend/CacheClip/
  MiniPIC 一脉"KV cache 作为文档知识存储介质"思路的正面对比性数据点，为该技术路线相对
  RAG/参数化微调的定位提供了受控实验证据；9/15 挂出，本轮 watchlist/venues 检索新收录。
