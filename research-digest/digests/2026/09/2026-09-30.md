### ⚠️ 竞品预警

- **RoleKV: Role-Aware KV Cache Management for the Inverted Age-Importance of LLM Agent Context**（OpenReview，https://openreview.net/forum?id=of1W47Odj1；未找到 arXiv ID，提交日期未能核实）— 训练无关、无损的服务层策略：轻量 Role Tagger 给每个 KV block 打语义角色标签（system prompt / tool output / CoT 等），按角色校准的衰减决定 block 驻留位置（GPU vs CPU/disk），而非按 recency；报告抢占减少最多 31%、PCIe 流量减少 35%、HotpotQA 端到端 1.34×（8B–70B）。
  - 重叠点：用 agent 上下文的语义/结构信号（block 角色）驱动 KV 层保留决策，不走文本重发，与 MemDecay（区域感知衰减）同一思路，落在 StructKV 的 P2 决策信号侧。
  - StructKV 剩余差异：(1) RoleKV 只决定 block 放哪一层（分层/卸载），**不做 prune + position reindex**，显存占用与注意力开销不变（P1 无重叠）；(2) 角色标签是粗粒度、按 block 的静态类别，不含 episode 边界 / 工具调用状态 / 覆盖-重试-失败标记 / 依赖图（P2 的 E2 分歧率、E3 消融仍可占位）；(3) 无协议层（P3）。
  - 对 StructKV 的意义：**P2 E1/E3**——可作为"角色/区域类信号"档的对照 baseline（与 MemDecay 并列），E3 消融应覆盖"仅角色标签 vs 完整结构状态"。
- 核心竞品名单（Leyline / IntentKV / MemDecay / Beyond Compaction / TokenPilot / CodeComp / SmoothAgent / Stateful delta-only / SideQuest / Models Take Notes at Prefill）本轮按名称 + arXiv ID 搜索，**未检索到新版本或新的 follow-up**（arxiv.org 无法直接抓取，版本号变化只能靠搜索结果侧面判断，可能有遗漏）。
