- **RunningTensor: Generalizing Linear Attention to Higher-Order Recurrent States**（arXiv 2609.12814，
  9/11）—— 提交时间超出 24-48 小时窗口（约 9 天前），且属线性注意力理论泛化工作而非 KV cache 管理主题，
  时间+相关性双重排除。
- **Token Latency Fairness: Performance Isolation for Multi-Tenant LLM Serving**（arXiv 2609.18112，
  9/16）—— 多租户延迟公平调度机制，未针对 KV cache 层做专门设计，按 deprioritize 规则过滤（此前已过滤过
  一次）。
- **HyQuant: Hybrid-Precision Quantization for LLM Attention**（arXiv 2608.27875v3）—— 聚焦通用 attention
  量化而非明确的 KV cache 压缩/驱逐机制，相关性偏弱，过滤。
- **gauravapiscean/agentic-kv-cache**（GitHub repo，约 9/10）—— 用 393 个 Claude Code session、6.8 万条真实
  请求复现/质疑近期 agentic KV cache eviction 策略论文的声称，指出简单 LRU 比多数"高级"策略更难打败，且
  部分对比论文的模拟器存在会人为抬高非 LRU 策略表现的 bug；主题高度相关但发布已超窗口（约 10 天前），
  未收录为新条目，记录于此供后续对 KV eviction 论文做批判性交叉参考。
- **fsdatalab/quail issue #111**「Add automatic prefix caching across rows」（约 9/17，略超 48 小时窗口）——
  明确的 KV cache 机制问题：Quail 目前仅按 document identity 复用 KV，未利用跨行相同 token 前缀，在
  AGENT-1 workload 上产生 1189 万个重复计算的 KV token（vLLM 自带 automatic prefix caching 同一 workload

  scheduling LLM serving" 关键词下的中等置信度背景参考。

  cache where it pays」（创建于 9/20，落在窗口内）—— 内部 Rust crate 中"encoded state"复用的功能请求，
