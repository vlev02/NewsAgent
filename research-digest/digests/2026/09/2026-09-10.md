### 🔥 今日必看

- **KVShareArena: KV-Cache Reuse Across Contexts and Model Checkpoints**
  （arXiv 2609.10266，Xi Shi / Qian Lou，9/9 挂出）—
  现有 serving 系统只在"复用文本位于 prompt 最前端"这一严格前缀条件下才做 KV 复用；
  这篇构建 benchmark，专门测两类会打破该前缀条件的场景：RAG server 每次查询拼接
  不同检索片段、多 agent coordinator 读取其它 agent 写的报告。核心发现——仅做位置
  修正（无需重算）在只需单一来源时就够用，但一旦问题需要同时综合多个来源，只有
  "付费"方法（部分重编码或训练）才能挽回一半到三分之二的差距；未修复的 cache 甚至
  比完全不用 cache 更差。这既是 tier_0 KV cache reuse / position re-indexing 的
  系统性量化研究，又直接落在 tier_2 agentic 场景（多 agent 间 cross-context KV 复用）
  ——同时命中两个 tier 且给出可操作的"什么时候该重算"判据，是本轮质量最高的一条；
  egress 限制下未能直读全文，具体数值以摘要/搜索二次信息为准，待下一轮核实细节。
