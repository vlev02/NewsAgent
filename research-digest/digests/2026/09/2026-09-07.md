### 🗑️ 过滤掉的

- **Invalidation Contracts for Cross-Episode Agent Memory**（arXiv 2609.00243，9/1 挂出）— 针对 agent 跨 episode 缓存 API 报错的"恢复建议"，给每条建议附加版本戳和可缓存性提示以便客户端安全驱逐过期条目；这是纯文本层的建议/知识缓存协议，未触及 KV cache 或 serving 层机制，按 deprioritize 规则中"纯文本 agent memory（不触及 KV cache 时）"过滤。
- **ContextPipe: Database-Inspired Context Assembly for Long-Horizon Agents**（arXiv 2609.00749，9/1 挂出）— 把 context 组装类比为数据库查询执行（Plan-Bind-Optimize-Execute-Feedback 五阶段管线），在 SWE-bench Pro 子集上比 append-only 策略减少 31% token 量、23% LLM 调用次数，但代价是更低的 KV cache 命中率；核心贡献落在"上下文组装的查询优化"而非 KV cache 机制本身，只是报告了对 KV 命中率的副作用。判定为边界案例，暂不收录，留待关键词库迭代时讨论 tier_2 是否要覆盖这类"context 组装系统但会报告 KV 代价"的工作。
- 常规 tier_0（KV cache compression/eviction/reuse/prefix caching/attention sink/StreamingLLM/token pruning）、tier_1（PagedAttention/disaggregated prefill-decode/offloading/speculative decoding）检索命中大量论文（如 KV Packet 2604.13226、CacheTune 2605.24022、ObjectCache 2605.22850 等）发布时间在 4-6 月，超出 7 天已收录窗口但又不属于"过去 24-48 小时新内容"，为避免今日 digest 变成历史积压清单，暂不逐条补录，仅记录于此供后续如需系统性补漏时参考。
