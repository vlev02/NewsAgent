### 📄 新论文（按 tier 分类，每条一行：标题 + 一句话 takeaway）

#### KV Cache 压缩/驱逐

- **MetaKV: Adaptive KV Cache Compression for Constrained LLM Inference**（arXiv 2609.07966）—
  现有 KV cache 压缩方法在精度/延迟/峰值显存之间的权衡因 prompt 而异，单一固定配置难以适配不同资源
  约束场景；提出 MetaKV，用轻量预测模型逐 prompt 估计候选配置（横跨 KVQuant/H2O/RocketKV 三类方法共
  十种配置）的端到端延迟、峰值显存与正确率，在满足用户指定延迟/内存预算下自动选取最优配置。是把
  "该用哪种压缩方法"本身当作可学习决策问题的新数据点，与已收录的各类固定式重要性打分/量化方法构成
  互补（元层面选择而非新压缩算法本身）；9/7 挂出，超出 24-48h 窗口但发布未满一周且此前未收录，本轮
  tier_0 检索按索引延迟缺口补录。

#### Agentic Context 管理

- **Bio-MemArt: Biometric-Aware KV Cache Memory for Multi-User LLM Agents**（arXiv 2609.08566）—
  指出 KV cache 正从纯 serving 优化演变为长程 agent 的外部记忆底座，但多用户共享部署下语义相关性
  本身无法判断某条可复用 KV block 是否授权给当前物理用户；提出为每条存储的 KV memory block 附加
  归一化生物特征模板，先用当前用户的生物探针过滤共享内存池，再在授权候选池内运行原有 MemArt 检索
  与 KV 复用管线，在保留 latent-space 检索/直接 cache 复用/解耦位置编码的同时加入物理用户访问控制；
  长期对话 QA 的人脸与掌纹 benchmark 上验证 owner/non-owner 查询区分度。与已收录的 agent 记忆/KV
  复用系统构成正交延伸——在 KV 复用能力之上补齐多用户隐私隔离维度；9/8 挂出，本轮 tier_2/tier_4
  联合检索补录（索引延迟）。
- **Forgetting Without Restarting: Execution-State Unlearning for Stateful LLM Agents**
  （arXiv 2609.04875）— 指出长程 agent 是有状态的，会积累压缩摘要、明文记忆、待执行工具计划与
  KV cache，现有"遗忘"操作只删除明文记忆记录，由被撤销信息派生的所有产物（含 KV cache 中的痕迹）
  仍完整保留；将该问题形式化为 execution-state unlearning，把 agent 运行时建模为确定性转移系统，
  证明精确遗忘至少需要重算 T-τ+1 步转移；提出 Provenance-Guided Selective Replay，用跨
  prompt/压缩记忆/cache 三层的 provenance graph 定位注入点，并通过 **cache cropping** 做
  checkpoint 恢复。是 KV cache 在 agent 场景下作为需要被"精确遗忘"对象这一新问题维度上的首批工作，
  与已收录的 KV cache reuse/eviction 机制构成正交延伸（隐私遗忘 vs 效率优化）；9/4 挂出，本轮
  tier_4 检索补录（索引延迟）。
