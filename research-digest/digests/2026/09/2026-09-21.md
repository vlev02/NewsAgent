### 📄 新论文（按 tier 分类，每条一行：标题 + 一句话 takeaway）

#### KV Cache 压缩/驱逐

- **TierKV: Long-Context On-Device LLMs via Predictive Multi-Tier KV Caching**（arXiv 2609.21172）—
  现有 KV cache 分层/卸载方案多是被动式：先驱逐或溢出，需要时再重建，带来延迟开销；本文提出预测式
  多层 KV 缓存（PMCO），在 decode 前基于 prefill 隐藏状态预测未来 token 的缓存需求，主动把 token
  预先分配到精确/低秩近似/flash 卸载三个层级；移动端 8 个模型上 prefill 吞吐最高提升 17.6 倍，
  RAM 驻留 KV 显存降低 12.5%-34%；9/18 挂出，本轮 tier_0/watchlist 联合检索新收录。
- **Elastic Threshold Attention: Learned Contextual Sparsity for Long-Context Decoding**（arXiv
  2609.20888）— 现有稀疏 attention/KV 筛选方法多用固定阈值或固定 top-k，难以适应不同 query/上下文
  的实际稀疏度；本文学习动态、上下文相关的稀疏阈值，用 Triton kernel 在 O(1) 时间内筛选需要参与
  计算的 KV 块，长上下文解码相比 FlashAttention-2 最高提速 2.5 倍；9/16 挂出，本轮 watchlist 检索
  新收录，属 token pruning/动态 KV 筛选子方向的最新数据点。

#### KV Cache 复用 / Position Re-indexing

- **On-Demand Attention: Language Models Know When to Recall**（arXiv 2609.20734）— 现有 KV cache
  驱逐/压缩方法隐含假设一旦决定丢弃某段历史就不再需要；本文只训练一个轻量"回忆头"（recall head）
  预测每个解码步是否需要调用全局 attention 访问完整历史 KV，其余步骤走局部优先解码，完整历史 KV
  缓存本身并未被物理丢弃、可按需访问；在 vLLM 中实现 GPU 侧条件执行获得实际解码加速；与本项目长期
  关注的"驱逐是否不可逆"这条主线相关——用可学习的按需召回替代一次性驱逐判断；9/17 挂出，本轮
  tier_1/watchlist 联合检索新收录。

#### Systems / Serving

- **PrefixBench-H100: Characterizing Prefix Reuse and Time-to-First-Token in H100 LLM Serving**
  （arXiv 2609.19657）— 面向前缀 KV 复用系统缺少统一可复现评测这一空白，本文在单张 H100 上对
  vLLM 与 TensorRT-LLM 做前缀复用基准测试，系统刻画共享前缀长度/并发度/缓存配置对 TTFT 收益与
  缓存维护开销的权衡边界，发现不同引擎间运行时差异主要来自调度层而非缓存算法本身；作为横向对比
  参照资源收录，类似此前已收录的 Benchmarking KV-Cache Optimizations（2607.05399）；9/17 挂出，
  本轮 tier_1 检索新收录。

### 🗑️ 过滤掉的

- **Marginal utility, matrix factorization, and the Key-Value (KV) cache: a unified
  information-economic framework for sovereign geo-mining inference**（arXiv 2609.20068，v11）—
  用边际效用经济学框架统一解释矩阵分解与 KV cache 驱逐/低秩压缩的"最优保留"规则，但应用场景是
  小众的地矿文档信息抽取、已有 11 次修订，理论包装下与 KV cache 系统实践的真实相关性偏弱，过滤。
- **MeshKV: A Network-on-Chip KV Cache Fabric for Scalable Transformer Decoding Accelerators**
  （arXiv 2609.19207，约 9/16）— FPGA/NoC 互连硬件工作，虽涉及 KV cache 数据搬运，但属硬件互连
  fabric 而非 KV cache 算法/系统层面的贡献，且提交时间超出窗口，按相关性+时间双重排除。
- **SpecQuant: Speculative Decoding with Multi-Parent Quantization for Adaptive LLM Inference**
  （arXiv 2609.21704，9/18）— 匹配"speculative decoding"关键词，但核心是对草稿模型变体做量化，
  未触及 KV cache 本身的管理机制，过滤。
- **ContextPipe: Database-Inspired Context Assembly for Long-Horizon Agents**（arXiv 2609.00749）—
  匹配"long horizon agent context window"，但核心是减少 LLM 调用次数/token 量的上下文组装机制，
  未落到具体 KV cache 层面操作，且提交时间（9/1）超出窗口，双重排除。
- **TOPAS: Workflow-Aware Prefix-State Scheduling for Multi-Agent LLM Serving**（arXiv 2608.25523）
  与 **GraniKV: Asymmetric Granularity KV-Cache Paging for Multi-Agent Systems**（arXiv 2608.15584）—
  均为真正命中"shared prefix cache multi-agent"的 KV 机制类论文，但均为 8 月下旬旧文，超出窗口，
  此前轮次已核查过，本轮不重复收录。
- **KVShareArena: KV-Cache Reuse Across Contexts and Model Checkpoints**（arXiv 2609.10266，9/9）—
  已于 9/10 digest 收录（🔥今日必看），本轮再次出现于搜索结果中，因超出窗口且已收录不重复列出。
